Public transparency information for the private/internal API client used in VoltWorth Finance's YouTube publishing workflow.

Effective date: August 9, 2026

Private/internal use only: VoltWorth Finance Publishing Automation is not offered to the public. This public website does not expose a public OAuth login, customer publishing dashboard, or access to the internal publishing client.
Functionality

A narrow YouTube publishing workflow.

Authorize

The authorized channel owner grants the permissions required for the disclosed publishing functions.

Upload

Approved VoltWorth Finance videos and associated publishing metadata can be uploaded through the YouTube Data API.

Verify

Limited read-only API checks verify channel identity, uploaded-video presence, processing state, privacy/publication state, and related workflow results.

Revoke

The authorized Google Account owner can revoke the application's access through Google Account connection settings.
